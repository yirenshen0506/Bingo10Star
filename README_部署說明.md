# 賓果賓果 10 星瀏覽器版

## 上傳 GitHub Pages
1. 解壓縮 ZIP。
2. 在 GitHub 專案根目錄上傳解壓後的所有內容；`index.html` 必須直接位於根目錄，`assets` 必須是一個資料夾。
3. Commit changes。
4. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save。
5. 部署完成後網址為 `https://yirenshen05.github.io/Bingo10Star/`。

## 使用說明
- 匯入每期 20 個 01–80 號碼的 CSV / JSON，或貼上每期一行的 20 個號碼。
- 按「產生一組推薦」取得一組 10 號碼。
- 可執行簡易回測，並匯出 JSON 備份。
- 資料存在目前瀏覽器的本機儲存空間，清除瀏覽資料可能導致資料遺失，請定期匯出備份。
- 本版本不包含已驗證的官方即時開獎 API 串接；匯入資料需自行確認正確性。
- 歷史統計僅供娛樂與研究，無法預測或提高隨機開獎的中獎機率。
